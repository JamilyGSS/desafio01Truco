# Truco Paulista — 02 Duplas

Projeto de desenvolvimento de um sistema de Truco Paulista para duas duplas, como atividade da disciplina de Análise de sistemas de software da Universidade Estadual de Maringá (UEM).

## Etapas do projeto

- Especificação de todos os casos de uso do sistema.
- Desenvolvimento da camada gráfica para interação dos jogadores com o jogo.

## Interface gráfica

A interface gráfica foi desenvolvida em HTML e está disponível neste repositório.
